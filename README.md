# Nutricomp 2.0 — Prévia funcional

Este repositório vazio foi usado como **área provisória de prévia**, sem alterar o site público da Nutricomp nem os outros projetos da conta.

## O que funciona
- Site responsivo para **marmitas de 350 g**.
- Combos: **10 por R$ 220**, **20 por R$ 380**, **30 por R$ 510**.
- Busca e seleção por categorias, com totalizador e lista de pratos.
- **Limite automático de 2 frutos do mar por combo**.
- Finalização pelo WhatsApp: uma mensagem com pratos, quantidades, preço e observações vai para (11) 93394-4302.

## Ver a prévia
O arquivo `index.html` e a pasta `assets/` formam um site estático. Para disponibilizar um endereço visitável pelo navegador, abra **Settings → Pages → Build and deployment → Deploy from a branch** e selecione **main / (root)**. O GitHub exibirá o link quando a publicação estiver ativada.

## Antes da publicação definitiva
- Confirmar itens suínos e vegetariano que vieram do catálogo anterior.
- Importar do sistema atual as fotos reais e fichas nutricionais autorizadas, sem inventar informações.
- Revisar taxas de entrega, disponibilidade, políticas e proteção de dados.
- Migrar posteriormente para um repositório específico `nutricomp-site`, se desejado.

A prévia não recebe pagamentos nem calcula frete; os dados do pedido são enviados pelo WhatsApp e a equipe confirma os detalhes.
